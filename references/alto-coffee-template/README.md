# alto-coffee-template — source code

Live demo: https://kedhar-components.pages.dev/#alto-coffee-template

Folders under components/ are React + TypeScript + Tailwind components.
Main file: components/alto-coffee-template/alto-coffee-template.tsx  (usage example: components/alto-coffee-template/demo.tsx)

Put each folder's .tsx file at src/components/ui/<folder>.tsx in a
shadcn-style project (the code imports siblings as @/components/ui/<name>).

npm packages used: gsap, react
